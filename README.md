# Smart-Multi-Face-Tracker-with-Real-Time-Audio-Announcement
Developed a real-time computer vision application using Python,OpenCV,and pyttsx3 that detects multiple faces,assigns unique persistent IDs using Euclidean centroid tracking, and provides automated voice announcements of the active crowd/face count without video latency using multithreading.

## 🛠️ Technologies Used

- **Python** – Core programming language
- **OpenCV** – Real-time image and video processing
- **Haar Cascade Classifier** – Face detection
- **NumPy** – Image and array processing
- **Pyttsx3 / Text-to-Speech** – Real-time audio announcements
- **Webcam** – Live video input

## ✨ Key Features

- 👥 **Multi-Face Detection** – Detects multiple faces simultaneously in a live video stream.
- 🎯 **Real-Time Face Tracking** – Continuously tracks detected faces across video frames.
- 🎥 **Live Webcam Processing** – Processes webcam video in real time.
- 🔲 **Face Bounding Boxes** – Displays bounding boxes around detected faces.
- 🔊 **Real-Time Audio Announcement** – Announces the number of detected faces using text-to-speech.
- 📊 **Dynamic Face Count** – Updates the detected face count as people enter or leave the camera view.
- ⚡ **Real-Time Processing** – Performs face detection and tracking continuously.
- 🖥️ **Interactive Display** – Shows the live camera feed with detection results.
- ❌ **Easy Exit** – Allows the user to stop the application using a keyboard command.

## 🎯 Project Objective

The objective of this project is to develop a real-time computer vision system capable of detecting and tracking multiple faces while providing audio announcements of the detected face count.
